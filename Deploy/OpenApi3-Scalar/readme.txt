Scalar for OpenAPI 3 documents
==============================

This folder contains the Scalar 1.72.1 distribution, an alternative to the Swagger UI files of the OpenApi3
folder. Both interfaces read the same document, so you can publish the two and let the reader choose, or keep
only the one you prefer.

Files
-----

- index.html: the page and its configuration. The url option of Scalar.createApiReference points to
  ../OpenApi3/openapi.json, the document generated by the SampleOpenApi3 demo. Change it to the address where
  your web server publishes the file, for example /api/help/openapi.json, or copy the document next to this
  page and use ./openapi.json.
- standalone.js: the whole interface, in one file. It can be downloaded from
  https://cdn.jsdelivr.net/npm/@scalar/api-reference/dist/browser/standalone.js or from the
  @scalar/api-reference npm package.
- scalar.LICENSE.txt: the MIT License of Scalar.

Copy this folder to your web server, together with the generated document. Scalar needs these two files only.

When the page is opened directly from the file system the browser blocks the request that loads the document,
so a web server is required.

Theme
-----

The page opens with the dark theme, whatever the theme of the operating system, and the switch at the bottom
of the sidebar changes it. To open with the light theme by default, change darkMode to false in index.html.

What Scalar renders
-------------------

Neither Scalar nor Swagger UI covers the whole OpenAPI 3.2 specification yet, and they do not cover the same
part of it. All the objects are present in openapi.json.

Scalar 1.72.1 renders the webhooks and the hierarchy of the tags, which Swagger UI 5.32.15 does not. It also
renders the QUERY method, the querystring parameter (under the query parameters of the operation), the cookie
parameters and the deprecated ones. In exchange it does not render the callbacks nor the links of the
responses, which Swagger UI does. Neither of them renders the operations declared under additionalOperations.

Scalar also reads Swagger 2.0 documents, which it converts to OpenAPI 3.1 while it loads. The Swagger2-Scalar
folder has the same files pointing to the swagger.json of the Swagger2 folder.
