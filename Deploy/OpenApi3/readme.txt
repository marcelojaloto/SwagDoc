Swagger UI distribution for OpenAPI 3 documents
===============================================

This folder contains the Swagger UI 5.32.15 distribution files and the openapi.json file generated by the
SampleOpenApi3 demo (Demos\SampleOpenApi3). Copy the whole folder to your web server to publish the
documentation of your API.

Files
-----

- openapi.json: the document generated by SwagDoc with SpecVersion = svOpenApi3. It follows the latest
  OpenAPI 3.x release supported by SwagDoc (the value of the openapi field of the document).
- index.html, index.css, swagger-ui.css, swagger-ui-bundle.js, swagger-ui-standalone-preset.js,
  oauth2-redirect.html, favicon-16x16.png, favicon-32x32.png: the Swagger UI distribution files.
  index.css hides the logo and the address field with the Explore button of the Swagger top bar and keeps
  only its light bulb theme button, fixed in the top right corner. Remove the topbar rules of index.css to
  show the complete top bar again.
- swagger-initializer.js: the Swagger UI configuration. The url option points to the openapi.json file
  of this folder. Change it to the address where your web server publishes the file, for example
  /api/help/openapi.json. The file also sets the theme of the page (see below).
- LICENSE, NOTICE and the *.LICENSE.txt files: the Apache License 2.0 of Swagger UI.

Swagger UI renders OpenAPI 3.0, 3.1 and 3.2 documents starting from the 5.x releases. When you update the
distribution files, keep a release that supports the OpenAPI version written by SwagDoc. Swagger UI 5.32.15
only displays the webhooks section for OpenAPI 3.1 documents, so the webhooks of the generated 3.2 document
are not listed on the page, although they are present in openapi.json.

Theme
-----

The page opens with the dark theme, whatever the theme of the operating system. The original light bulb
button of Swagger UI, in the top right corner, switches between the dark and the light themes, and the
browser remembers the last choice
(local storage key swagger-ui-theme). The theme parameter of the address selects a theme for that visit
without changing the remembered choice, for example index.html?theme=light or index.html?theme=dark.
To open with the light theme by default, change the value of defaultTheme to 'light' at the beginning of
swagger-initializer.js.

The source map files (*.map) of the distribution were not copied because they are only used for debugging
Swagger UI itself. The complete distribution can be downloaded from
https://github.com/swagger-api/swagger-ui/tree/master/dist or from the swagger-ui-dist npm package.

The SampleOpenApi3 demo writes its executable and the generated file in this folder, so the openapi.json
file is updated after running the demo and clicking "Generate".

To open the page from a web server, point the browser to the index.html file. When the page is opened
directly from the file system the browser blocks the request that loads openapi.json, so a web server is
required.
