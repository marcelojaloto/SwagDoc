Scalar for Swagger 2.0 documents
================================

This folder contains the Scalar 1.72.1 distribution, an alternative to the Swagger UI files of the Swagger2
folder. Both interfaces read the same document, so you can publish the two and let the reader choose, or keep
only the one you prefer.

Files
-----

- index.html: the page and its configuration. The url option of Scalar.createApiReference points to
  ../Swagger2/swagger.json, the document generated by the SampleApi demo. Change it to the address where your
  web server publishes the file, for example /api/help/swagger.json, or copy the document next to this page
  and use ./swagger.json.
- standalone.js: the whole interface, in one file. It can be downloaded from
  https://cdn.jsdelivr.net/npm/@scalar/api-reference/dist/browser/standalone.js or from the
  @scalar/api-reference npm package.
- scalar.LICENSE.txt: the MIT License of Scalar.

Copy this folder to your web server, together with the generated document. Scalar needs these two files only.

When the page is opened directly from the file system the browser blocks the request that loads the document,
so a web server is required.

Theme
-----

The page opens with the dark theme, whatever the theme of the operating system, and the switch at the bottom
of the sidebar changes it. To open with the light theme by default, change darkMode to false in index.html.

Swagger 2.0 documents
---------------------

Scalar does not implement Swagger 2.0: it converts the document to OpenAPI 3.1 while it loads, and the page
shows the badge "OpenAPI 2.0" next to the title. The definitions, the body parameters and the consumed media
types of the document are displayed after that conversion.
