Deploy folders
==============

Each folder contains the Swagger UI distribution files and the document generated by SwagDoc for one
family of the specification.

- Swagger2: the swagger.json file generated by the SampleApi demo (SpecVersion = svSwagger2, the default)
  and the Swagger UI files that render it.
- OpenApi3: the openapi.json file generated by the SampleOpenApi3 demo (SpecVersion = svOpenApi3, which
  writes the latest OpenAPI 3.x release supported by SwagDoc) and the Swagger UI 5 files that render it.

Scalar is an alternative interface, distributed in two files, and each family has a folder with it:

- Swagger2-Scalar: renders the swagger.json file of the Swagger2 folder.
- OpenApi3-Scalar: renders the openapi.json file of the OpenApi3 folder.

Both interfaces read the same document, so you can publish the two and let the reader choose, or keep only
the folder of the one you prefer.

Read the readme.txt file of each folder to know how to point the page to the address where your web server
publishes the generated file, and what each interface renders of an OpenAPI 3.2 document.
